# VELTRIX Brokerage Website Starter

A responsive, dark premium-fintech **front-end concept** built with plain HTML, CSS, and JavaScript. It is intentionally easy to preview and edit without installing Node.js or other packages.

## Preview locally

1. Extract the ZIP.
2. Open `index.html` in a modern browser.

For a local development server, you can use VS Code's Live Server extension or run `python -m http.server 8000` in this folder and open `http://localhost:8000`.

## Included

- Public marketing homepage and responsive navigation
- Market snapshot cards with clearly simulated data
- Login, registration, and password recovery preview forms
- Client dashboard, markets, portfolio, accounts, wallet, deposits, withdrawals, transactions, verification, support, and settings screens
- Admin overview, customer list, verification queue, transaction monitoring, support inbox, and audit-log preview
- Responsive mobile layouts, keyboard focus styles, and reduced-motion support
- Honest demo notices: no actual authentication, support messaging, KYC uploads, money movement, or trading

## Important production gap

This is **not a live brokerage platform**. It has no backend, database, real authentication, payment provider, identity verification service, live market feed, trade execution, or server-side admin authorization. All balances, prices, customers, and transactions are fictional. Do not use it to collect real customer information or money.

Before a real launch, engage qualified security and compliance professionals and implement jurisdiction-appropriate licensing/compliance, secure authentication and MFA, backend authorization, encrypted data handling, audited transaction ledger, payment integrations, KYC/AML workflows, support operations, monitoring, backups, disaster recovery, and load testing. Do not claim capacity for one million concurrent users until validated with representative load tests.

## Main files

- `index.html` — page structure and homepage content
- `styles.css` — design system, layout, and responsive styles
- `app.js` — client-side demo routing and interactions
